# Decisiones (ADR)

Un archivo por decisión, numerado y con fecha. Se agregan, no se editan: si una decisión se revierte, se escribe otra que la supersede.

Corresponde un ADR cuando una decisión **no puede derivarse** de `brief.md` o `principios.md`. Si eso ocurre seguido, probablemente el brief esté incompleto.

Formato: ver `0000-plantilla.md`.
