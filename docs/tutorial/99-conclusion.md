# Conclusión

Corriste dos comandos: uno para instalar y otro para revisar. Todo lo demás lo dijiste hablando, y quedó escrito por alguien que no eres tú.

Lo que hay en disco son archivos de texto. Ábrelos con lo que quieras, edítalos con lo que quieras, léelos en veinte años. Si desinstalas TUKU mañana siguen ahí y siguen entendiéndose solos, porque nunca fueron una base de datos disfrazada ([principio 1](../principios.md)).

Tres archivos hacen casi todo:

| | |
|---|---|
| `AHORA.md` | Lo que pasó, con su hora |
| `PENDIENTES.md` | Lo que sigue abierto |
| `AGENTS.md` | Lo que tu agente sabe, y que puedes cambiar |

Y en cada frase que dices se repite una sola decisión: si lo que contaste dejó algo abierto, cerró algo que estaba abierto, o ninguna de las dos. Esa la toma tu agente, y es lo único de todo el proceso que no es mecánico.

Lo demás son consecuencias, y las consecuencias son baratas cuando alguien las aplica siempre.
