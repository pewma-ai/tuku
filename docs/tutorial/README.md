# Tutorial

> Una semana de trabajo, dictada a un agente. Cada capítulo te dice qué pedir. Los archivos te dicen qué pasó.

Vas a instalar TUKU, abrir un agente sobre una carpeta y hablarle con naturalidad. Eso es todo.

El tutorial no anticipa los resultados a propósito: te indica dónde mirar. Es más rápido descubrirlo que leerlo, y lo que descubres se asimila mejor.

Toma menos de una hora. Puedes pausar en cualquier capítulo: lo que lleves escrito queda utilizable.

## Sobre el comando `tuku`

Existe, tiene múltiples funciones, y casi nunca lo vas a escribir directamente.

Lo utiliza tu agente por debajo. Por eso el tutorial te pide hablar y no teclear. Los únicos dos comandos que ejecutas tú son el de instalar (`tuku init`) y el de revisar (`tuku doctor`): el primero y el último del día uno.

## Qué vas a decir

Los ejemplos siguen el lunes de Andrea, que vende insumos escolares a colegios y trabaja sola, útil para tener qué decir sin necesidad de inventarlo.

Si prefieres utilizar tu propio día real, hazlo. Las indicaciones de cada capítulo aplican igual.
