# Reglas de todos los ámbitos

Lo que escribas aquí vale para todo lo que cuelgue de `ambitos/`.

Cuando una regla valga solo para una rama, escríbela en el `AGENTS.md` de esa rama. Ante dos reglas que aplican, gana la más cercana.

Puede quedar vacío. Está aquí para que sepas dónde escribir sin tener que preguntar.
